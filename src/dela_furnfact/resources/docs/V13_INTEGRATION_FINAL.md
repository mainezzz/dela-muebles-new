# V13 integración final

Este repositorio integra la línea v13 en una base única y estable.

## Incluye
- catálogo explícito de tipos de hueco
- distribución visual dentro del solver
- helpers de presentación centralizados
- módulos de arquitectura UI:
  - `state.py`
  - `controllers.py`
  - `render_controller.py`
  - `preview_state.py`
  - `preview_controller.py`
  - `window_actions.py`
  - `carpentry_state.py`
  - `carpentry_controller.py`
  - `app_flow.py`

## Estado
La GUI actual sigue funcionando sobre la base estable existente, y la arquitectura
v13 queda integrada en el repositorio para continuar la refactorización sin perder
la rama funcional del producto.
